# ☕ Brewora - Premium Coffee Ordering App

![Brewora App](https://AKASH80047.github.io/Premium-Coffee-Ordering-App/icons/Icon-192.png)

Welcome to **Brewora**, a highly professional and visually stunning premium coffee ordering application built with Flutter.

🔗 **[Live Demo on GitHub Pages](https://AKASH80047.github.io/Premium-Coffee-Ordering-App/)**

## ✨ Features
- **Modern & Professional UI:** Glassmorphism effects, auto-scrolling hero banners, and a clean boxed layout.
- **Dynamic Coffee Selection:** Browse popular coffees, view detailed product information, and manage favorites.
- **Smart Navigation:** Smooth onboarding, persistent bottom navigation, and highly responsive page transitions.
- **Profile Management:** Fully customizable profile section with local device image picking and intuitive sub-menus.

## 🚀 Getting Started

To run this project locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/AKASH80047/Premium-Coffee-Ordering-App.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Premium-Coffee-Ordering-App
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```

## 🛠 Tech Stack
- **Framework:** Flutter (Dart)
- **Deployment:** GitHub Pages (Web)
- **Key Packages:** `image_picker`, `google_fonts`, `shared_preferences`
